# Parallax Portfolio

A modern, animation-rich portfolio built with Next.js, featuring smooth parallax scrolling, 3D elements, and buttery-smooth motion.

![Next.js](https://img.shields.io/badge/Next.js-16-black)
![React](https://img.shields.io/badge/React-19-blue)
![Tailwind](https://img.shields.io/badge/Tailwind-4-38bdf8)

## ✨ Features

- 🎬 **GSAP animations** — timeline-based scroll and entrance animations
- 🖱️ **Lenis smooth scrolling** — inertia-based, silky scroll experience
- 🧊 **React Three Fiber + Three.js** — interactive 3D scenes and models
- 🎞️ **Framer Motion** — declarative UI transitions and micro-interactions
- 🎨 **Tailwind CSS 4** — utility-first styling with the new CSS-first config
- ⚡ **Next.js 16 + React 19** — latest App Router with React Compiler support

## 🚀 Getting Started

```bash
# Clone the repository
git clone https://github.com/Elyasforghani/Parallax-Portfolio.git
cd Parallax-Portfolio

# Install dependencies
npm install

# Run the development server
